# China Sourcing — поиск на китайских платформах

Цель: находить ФАБРИКИ (не трейдеров) под кастом-разработку одежды для мелких собак ≤5.5 кг
и амуниции, с контактами вне платформы. Результаты — только в файлы проекта
(`petshop/suppliers.md`, `petshop/recipients.json`) + короткий отчёт по-русски в чат.

## 1. Платформы: что реально работает из этой среды

| Платформа | Доступ отсюда | Что даёт | Как искать |
|---|---|---|---|
| **1688.com** | Частично: поиск за логином/капчей, карточки часто открываются | Внутренний оптовый рынок — цены на 20–40% ниже Alibaba, там сидят сами фабрики | НЕ ломиться в их поиск. Google/Bing: `site:detail.1688.com 宠物衣服` + товарные слова; открывать конкретные карточки curl'ом с UA браузера |
| **Alibaba.com** | Карточки и витрины открываются, поиск капризен | Экспортные фабрики, MOQ, Trade Assurance, витрина компании | `site:*.en.alibaba.com "pet apparel" OEM` через поисковик; на витрине искать раздел Company Profile → заявленный тип (Manufacturer/Trading) |
| **Made-in-China.com** | Обычно открывается полностью | Экспортёры, есть аудит-бейджи (Audited Supplier) | Прямой поиск на сайте работает; фильтр Business Type = Manufacturer |
| **Global Sources** | Открывается | Более крупные экспортёры, выставочники (Global Sources Fair) | Прямой поиск; смотреть Verified Supplier |
| **Yiwugo / Yiwu market** | Открывается частично | Мелочёвка/аксессуары дёшево, но почти всё трейдеры | Только для волны 2 (миски, игрушки) |
| Taobao/Tmall | Розница, за логином | Только как разведка розничных цен внутри Китая | Через поисковики по `site:item.taobao.com` |

Правила среды: robots.txt уважать; 1 запрос за раз, backoff; Cloudflare/логин-стена =
СТОП, помечаем `MANUAL_CHECK` с точным URL — не обходить. WebFetch может быть заблокирован
на китайских доменах — использовать Bash curl с браузерным User-Agent и таймаутом 20с.

## 2. Словарь запросов (китайский обязателен для 1688)

Базовые: 宠物衣服 (одежда для питомцев) · 狗衣服 (собачья одежда) · 小型犬 (мелкие породы) ·
宠物服装工厂 (фабрика одежды) · OEM代工 / ODM贴牌 (контрактное производство) ·
来图来样定制 (кастом по эскизам/образцам — КЛЮЧЕВОЙ маркер под нашу модель).
По категориям: 狗狗羽绒服 (пуховик) · 四脚衣 (одежда на 4 лапы!) · 狗卫衣 (худи) ·
狗毛衣 (свитер) · 灯芯绒 (вельвет) · 狗牵引绳 (поводок) · 胸背带 (шлейка) · 项圈 (ошейник).
Гео-хабы: 东莞 (Дунгуань — шитьё) · 泉州 (Цюаньчжоу) · 杭州 (Ханчжоу) · 青岛 (Циндао) ·
广州 (Гуанчжоу — амуниция).

Шаблон: `site:detail.1688.com 四脚衣 来图来样` или `宠物衣服 工厂 OEM 东莞 -批发`
(−批发 отсекает часть чистых оптовиков).

## 3. Фабрика vs трейдер — чек до внесения в шорт-лист

1. **Витрина**: у фабрики фото цехов/линий, у трейдера — только товары. 1688: блок
   «工厂档案»/实力商家; Alibaba: Company Profile → «Manufacturer», годы, площадь, персонал.
2. **Ассортимент**: 300 разнородных категорий = трейдер. Узкая специализация = фабрика.
3. **Регистрация**: имя компании → поиск в 企查查/天眼查 (открываются частично) или просто
   Google: `"<company name>" 营业执照` — сверить уставной вид деятельности (制造 = производство).
4. **Кастом-маркеры**: 来图来样定制, 打版 (изготовление лекал), 样品 (сэмплы) в описании.
5. Совпадение адреса с промзоной производственного хаба, а не офисный центр.
Уверенности «фабрика» нет → помечать `trader?` и НЕ поднимать в приоритете.

## 4. Контакты — как в нашей RFQ-воронке

Платформенные чаты (旺旺/TradeManager) нам недоступны → искать выход на прямой канал:
корп-сайт в профиле → страница Contact (email!), WhatsApp/WeChat в шапке витрины,
телефон → не звонить, фиксировать. Email не выдумывать: только опубликованные на
собственных страницах компании. Нет прямого контакта → в recipients.json c `send: "form"`
или `send: "platform"` (ручная задача оператору с URL витрины).

## 5. Выход каждой сессии поиска

1. Новые кандидаты → `petshop/suppliers.md` (имя, платформа+URL, тип
   (factory/trader?/unknown), специализация, MOQ если виден, контакты, кастом-маркеры).
2. Достойные RFQ → `petshop/recipients.json` со статусом `approved_by_operator: false` —
   рассылка ТОЛЬКО после «ок» оператора.
3. Цены с карточек → `petshop/quotes-tracker.md` с пометкой «платформа, каталожная цена»
   (это НЕ котировка; наш бенчмарк: каталожное худи S $2.3–5.3, стёганое $3–7 ex-factory).
4. В чат — короткий отчёт по-русски: сколько просмотрено/отобрано, топ-3 с причинами,
   что упёрлось в логин/капчу (MANUAL_CHECK-список).
5. Коммит + push в рабочую ветку.

## 6. Анти-паттерны

- Не регистрироваться нигде и не логиниться (правило репо: never auto-register).
- Не принимать «золотой поставщик»/платные бейджи за верификацию — это реклама.
- Цену с карточки 1688 не считать достижимой FOB: +упаковка, +экспортные документы,
  +качество экспортного уровня; реальный FOB обычно ×1.3–1.8 от 1688-цены.
- Не слать RFQ с бренд-деталями (палитра, техпаки) кандидатам без проверки типа — сначала
  шорт-лист, потом одобрение оператора, потом только Design Brief.
