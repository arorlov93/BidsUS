# Chinese Dog Clothing & Accessories Manufacturers — Sourcing Notes
Research date: 2026-08-19 (session run 2026-09-03 environment). Researcher: Claude (sourcing agent).

## Method & limitations (read first)
- Tools: WebSearch only for content; WebFetch to manufacturer/B2B sites was **blocked by the environment egress proxy** for every external domain tried (petproducts.com.cn, chinapetclothing.com, p-nutspaws.com, xxmfs.cn, made-in-china.com, globalsources.com). All data below therefore comes from **public search-result snippets** of the companies' own sites and public B2B directory pages. No accounts, no logins, no scraping behind auth.
- Consequence: some fields could not be verified on the company's own page. Anything not seen in a public snippet is marked **не опубликовано**. Emails listed are company-level (info@/sales@) addresses that appear in public pages/snippets. No personal emails collected (one supplier, PetRova, publishes only a numeric qq.com address — omitted per rules).
- Provenance: everything here is `derived` from search snippets; treat MOQs and capacity claims as supplier self-reported, unverified.
